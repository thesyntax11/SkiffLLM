# Changelog

## 1.0.0

- Initial public release.
- Added a fully offline local LLM terminal assistant built on llama.cpp.
- Added interactive chat with streaming output.
- Added single prompt mode and stdin support.
- Added automatic GGUF model discovery.
- Added persistent session history.
- Added config file and environment variable support.
- Added slash commands.
- Added GPU layer offload configuration.
- Added sampling parameter controls.
- Added unit tests and CMake integration.
