# Project Localization

English is the primary language of SkiffLLM and stays the source of truth.
Localized files improve discoverability and make the project easier to explore
for non-English readers.

## Language map

| Language | README | Docs | Notes |
| --- | --- | --- | --- |
| English | `README.md` | `docs/` | Primary, source of truth, always current |
| Türkçe | `README.tr.md` | `docs/tr/` | Turkish |
| Deutsch | `README.de.md` | `docs/de/` | German |
| Español | `README.es.md` | `docs/es/` | Spanish |
| Français | `README.fr.md` | `docs/fr/` | French |

## Rules for translated docs

1. Keep command blocks, flag names, file paths, and code samples in English.
   They must remain copy-pasteable.
2. Translate prose and headings so that a native speaker reading only the
   localization gets the same information as the English version.
3. Do not invent features, flags, or numbers. When in doubt, ask or leave the
   item in English and add a note.
4. Keep terminology consistent within a language. Use a small glossary per
   language file if needed.
5. Keep the same section order as the English source so diffs are reviewable.

## What is in scope

- README (one translated file per language)
- User-facing docs under `docs/<lang>/`: INSTALL, SETUP, usage, FAQ,
  LIMITATIONS, GOOD_FIRST_ISSUES, and any future user-facing guide.

UI strings in the Android app, iOS app, and CLI error messages are out of scope
for the current localization effort.

## How to contribute

1. Pick a language and check the language map for existing work.
2. Translate from the current English `docs/` source, not from an older
   translation.
3. Keep the English-only content (commands, paths, code) unchanged.
4. Add or update the language entry in the README language menu.
5. Run `bash scripts/ci-local.sh` if you changed any script or C++.
6. Open a pull request that describes only the localization changes.

## Keeping translations current

When the English docs change, the language map entry for that file should be
updated. A stale translation is better than a missing one, but a translation
that contradicts the English source should be flagged as soon as possible.
